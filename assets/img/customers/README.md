# Customer photos ("In your kitchens")

1. Put the photo in this folder (JPG, roughly square, ~1000 px wide is plenty).
2. Add its file name to `customerPhotos` in `assets/js/site-config.js`.

A static site cannot look into a folder on its own, so step 2 is needed. While
that list is empty, the section does not appear on the product pages.

Only use photos whose sender has agreed to them being shown here.
